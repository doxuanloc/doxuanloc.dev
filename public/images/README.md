# Ảnh cho portfolio

Thả file ảnh vào đây theo đúng tên — site tự nhận lúc build. Thiếu file nào thì chỗ đó hiện **gradient AI/blockchain** thay thế (không bao giờ vỡ ảnh).

## Ảnh cá nhân
| File | Dùng ở đâu | Gợi ý |
|------|-----------|-------|
| `avatar.png` | Hero (Home) | Avatar minh hoạ của bạn (ảnh vuông, nền trong/đơn sắc) |
| `presenting.jpg` | Mốc "AI & Tối ưu" trong /journey | Ảnh thuyết trình (ngang/vuông, ≥800px) |

## Ảnh từng mốc timeline (`/journey`) — thả vào `journey/`
Đặt tên theo `id` của mốc, đuôi `.webp` / `.jpg` / `.png` đều được:

| File (trong `journey/`) | Mốc | Concept ảnh (AI/blockchain/tech) |
|------|-----|--------------------------------|
| `dai-hoc-nen-tang.webp` | 2018–2021 Nền móng | Thư viện/đại học, laptop & sách, hoàng hôn |
| `buoc-chan-frontend.webp` | 2022 Frontend | Code React + biểu đồ crypto xanh trong đêm |
| `fullstack-thuc-chien.webp` | 2022–2023 Full-Stack & 3D | Backend NestJS + mô hình 3D đang xoay |

> **Tối ưu trước khi thả:** nén về ≤150KB/ảnh (dùng squoosh.app hoặc `cwebp`). Tổng tất cả nên < 1MB để giữ Lighthouse cao.
> **Nguồn an toàn:** ảnh của bạn, Unsplash/Pexels (free commercial), hoặc AI-generated (model có license thương mại). Không hotlink, không dùng ảnh sản phẩm nội bộ công ty.
